# Power BI Dashboard Build

Import `../data/candidates_sample.csv` and `../data/candidate_skills.csv`. Create a 1-to-many relationship Candidates[CandidateID] -> CandidateSkills[CandidateID].

## Recommended pages
1. Recruitment Overview: KPI cards, applications by role, status funnel, monthly trend, source selection rate.
2. Candidate Insights: education, city, experience, resume score, top skills.
3. Source Performance: applications, shortlisted, selected and selection rate by source.

Use slicers for JobRole, Source, City, Education and ApplicationDate.
