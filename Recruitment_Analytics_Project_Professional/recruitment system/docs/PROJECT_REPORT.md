# Project Report — Recruitment Analytics & Candidate Insights

## Problem Statement
Recruitment teams receive applications from multiple channels but need a structured way to understand candidate volume, pipeline status, source effectiveness and skill availability.

## Solution
The project combines the existing recruitment web application with a structured analytics layer. Candidate/application data is analyzed using SQL and Python and visualized in Power BI.

## KPIs
- Total candidates
- Shortlisting rate
- Selection rate
- Applications by job role
- Selection rate by source
- Average experience
- Average resume score
- Average time to hire

## Deliverables
- Sample analytics dataset
- SQL analysis queries
- Python EDA script and notebook
- Power BI model and DAX measures
- Browser-based analytics dashboard
- Updated upload form for structured analytics fields
